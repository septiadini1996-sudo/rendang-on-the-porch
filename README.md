One sentence, 187 characters: my grandmother's beef rendang eaten with my fingers off a banana leaf on her porch in Padang, the rain hammering the tin roof, and the crispiest pieces she kept sneaking onto my side of the leaf. A small Node program writes that sentence to `entry.txt`, checking it against the bounty's 200-character gate before it writes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
